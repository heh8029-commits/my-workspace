→ 집에서 봇까지 켜려면 사무실 PC의 봇을 먼저 끄거나, 사무실 PC를 꺼야 합니다. 웹서버(5124·5125·5127)와 수집 예약작업은 겹쳐도 괜찮습니다.
✍️ 파일 만들 때 꼭 지킬 것 (오늘 사고 원인) · vbs 는 ANSI(cp949) 로 저장 — UTF-8 로 저장하면 한글 경로가 깨져서 조용히 안 돕니다
· bat 이 UTF-8 이면 2번째 줄에 chcp 65001 >nul 을 반드시 넣기
· ps1 을 예약작업에 걸 때는 -ExecutionPolicy Bypass 를 반드시 붙이기
1
먼저 갖춰야 하는 것
· 구글드라이브가 G: 로 붙어 있을 것 (다른 문자면 경로를 전부 바꿔야 합니다)
· Python 3.13 — C:\Users\사용자\AppData\Local\Programs\Python\Python313\
· Tailscale 로그인 (사무실 것을 볼 때만 필요)
· 패키지: pip install flask patchright openpyxl pandas python-telegram-bot requests
2
서버 3개만 먼저 켜기 (제일 안전)
봇이 아니라서 사무실 PC와 같이 켜져 있어도 아무 문제 없습니다.
# 상품관리·광고관리 (5127) python -X utf8 "G:\내 드라이브\미리토퍼캐슬\광고분석\상품관리_서버.py" # 광고리포트 (5125) python -X utf8 "G:\내 드라이브\미리토퍼캐슬\광고분석\ads_rebuild_server.py" # 그로스 웹 (5124) cd /d "G:\내 드라이브\런처바로가기\새로운그로스" && python -X utf8 app.py
3
시작프로그램 폴더 통째로 옮기기
사무실 PC의 이 폴더를 집 PC의 같은 자리에 복사하면 부팅 자동실행이 그대로 재현됩니다. 단, 봇 vbs 는 빼고 복사하세요 (위 경고). 복사한 뒤에는 인코딩이 ANSI 인지 꼭 확인하세요.
# 시작프로그램 폴더 열기 — 양쪽 PC에서 똑같이 explorer shell:startup # 지금 뭐가 들어있는지 보기 dir "%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup"
4
예약작업 옮기기
쿠팡·네이버 수집은 예약작업입니다. 사무실 PC에서 내보내기(XML) 하고 집 PC에서 가져오기 하면 됩니다.
C:\Users\A\ 안의 파일들도 같이 복사해야 합니다 (coupang_run.bat · coupang_ad_report.bat · naver_ad_run.bat · coupang_session_watchdog.ps1 · coupang_runner.py), 그리고 C:\scripts\run_notification.bat 도요.
# 사무실 PC — 예약작업 내보내기 schtasks /query /xml /tn "CoupangSalesCheck" > C:\temp\CoupangSalesCheck.xml schtasks /query /xml /tn "CoupangAdCheck" > C:\temp\CoupangAdCheck.xml schtasks /query /xml /tn "CoupangMongmongCheck" > C:\temp\CoupangMongmongCheck.xml schtasks /query /xml /tn "CoupangAdReport" > C:\temp\CoupangAdReport.xml schtasks /query /xml /tn "CoupangSessionWatchdog" > C:\temp\CoupangSessionWatchdog.xml schtasks /query /xml /tn "NaverAdBalanceCheck" > C:\temp\NaverAdBalanceCheck.xml # 집 PC — 가져오기 schtasks /create /xml C:\temp\CoupangSalesCheck.xml /tn "CoupangSalesCheck"
5
쿠팡·토글 엣지 세션 띄우기
이건 손으로 로그인해야 합니다. 프로필 폴더를 따로 쓰기 때문에, 창을 띄우고 한 번 로그인해 두면 계속 유지됩니다.
# 미리토퍼 (쿠팡) "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --remote-debugging-port=9301 --no-first-run --no-default-browser-check --user-data-dir="C:\Users\A\edge_profiles\미리토퍼" # 몽몽토퍼 (쿠팡) "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --remote-debugging-port=9302 --no-first-run --no-default-browser-check --user-data-dir="C:\Users\A\edge_profiles\몽몽토퍼" # 토글 "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --remote-debugging-port=9401 --no-first-run --no-default-browser-check --user-data-dir="C:\Users\A\edge_profiles\토글"
6
제대로 떴는지 확인
이 두 줄이면 지금 뭐가 살아있는지 한눈에 보입니다.
# 파이썬으로 도는 것 전부 powershell "Get-CimInstance Win32_Process -Filter \"Name LIKE '%python%'\" | ForEach-Object { $_.CommandLine }" # 열려 있는 포트 powershell "Get-NetTCPConnection -State Listen | Where-Object { $_.LocalPort -in 5000,5001,5123,5124,5125,5127,9301,9302,9401 } | Sort-Object LocalPort -Unique"
📌 기억해 둘 것 · 이 시스템은 구글드라이브 G: 위에 얹혀 있습니다. 드라이브가 안 붙으면 vbs 들이 최대 60초 기다렸다 포기합니다.
· 상품관리 화면의 메모·장바구니·작업목록은 광고분석\상품관리_상태.json 에 저장돼 드라이브로 동기화됩니다.
· 쿠팡 수집은 수동으로 여러 번 돌리면 안 됩니다 (봇차단 위험). 요청당 한 번만.
· 예전 start_all.ps1 · 전체시작.bat · 자동시작_등록.bat 은 지금 안 쓰입니다. 시작프로그램 폴더 방식으로 갈아탄 뒤 남아 있는 옛 방식입니다.
